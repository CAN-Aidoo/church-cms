═══════════════════════════════════════════════════════════════════════
STEP 3: DEPLOY ON RAILWAY.APP (5 minutes)
═══════════════════════════════════════════════════════════════════════

1. Go to: https://railway.app
2. Sign in with GitHub
3. Click "New Project" → "Deploy from GitHub repo"
4. Select your church-cms repository
5. Add MySQL database (click "+ New" → Database → MySQL)
6. Copy environment variables from: .env.production.example
7. Wait for deployment (~5 minutes)


═══════════════════════════════════════════════════════════════════════
STEP 4: GET FREE DOMAIN (4 minutes)
═══════════════════════════════════════════════════════════════════════

1. Go to: https://www.freenom.com
2. Search for your domain (example: gracechurch)
3. Select free extension: .tk, .ml, .ga, .cf, or .gq
4. Register for FREE (12 months)


═══════════════════════════════════════════════════════════════════════
STEP 5: CONNECT DOMAIN (2 minutes)
═══════════════════════════════════════════════════════════════════════

In Railway:
- Click your service → Settings → Domains
- Add custom domain: yourdomain.tk

In Freenom:
- Manage Domain → DNS Management
- Add CNAME record pointing to Railway URL
- Wait 10-30 minutes for DNS propagation


═══════════════════════════════════════════════════════════════════════
STEP 6: FINALIZE (1 minute)
═══════════════════════════════════════════════════════════════════════

Run migrations:
   railway run php artisan migrate --force

Create admin user:
   railway run php artisan tinker
   (Follow instructions in QUICK_DEPLOY.md)
