## 📱 QR Code Types & Use Cases

### 1. Service Attendance QR Codes
**Purpose**: Mark attendance for church services
**Generated By**: Admin before each service
**Validity**: 15 minutes before service → 30 minutes after service ends
**Location**: Displayed at church entrances, bulletin boards, projection screens

### 2. Event Registration QR Codes
**Purpose**: Register for programs, conferences, workshops
**Generated By**: Event coordinator (admin role)
**Validity**: From registration opening → event start time
**Location**: Promotional materials, social media, church website

### 3. Payment QR Codes
**Purpose**: Tithes, offerings, donations
**Generated By**: Finance admin
**Validity**: Service duration or campaign period
**Location**: Offering envelopes, giving stations, pew cards

### 4. Check-in QR Codes
**Purpose**: Children's ministry, service units, departments
**Generated By**: Department admin
**Validity**: 30 minutes before → 15 minutes after activity
**Location**: Department entrances, check-in desks

### 5. Visitor Registration QR Codes
**Purpose**: First-time visitor registration
**Generated By**: Admin/Guest services
**Validity**: Always active during service hours
**Location**: Welcome desk, visitor parking, entrance

### 6. Equipment Check-out QR Codes
**Purpose**: Borrow church equipment
**Generated By**: Equipment manager
**Validity**: Business hours only
**Location**: Equipment storage areas

### 7. Verification QR Codes
**Purpose**: Verify member identity for sensitive actions
**Generated By**: System admin
**Validity**: Single use, expires in 60 seconds
**Location**: Sent via secure channel

### Generation Process

```javascript
// Pseudo-code for QR generation
function generateQRCode(adminUser, config) {
  // Step 1: Verify admin authorization
  if (!verifyAdminRole(adminUser, 'QR_GENERATE')) {
    throw new Error('Unauthorized: Admin access required');
  }
  
  // Step 2: Create unique identifier
  const qrId = generateUUID();
  const timestamp = Date.now();
  
  // Step 3: Calculate expiration times
  const activation = calculateActivationTime(config);
  const expiration = calculateExpirationTime(config);
  
  // Step 4: Encode data
  const qrData = {
    id: qrId,
    type: config.type,
    churchId: config.churchId,
    serviceDetails: {
      date: config.date,
      type: config.serviceType,
      location: config.location
    },
    validity: {
      activates: activation,
      expires: expiration
    },
    security: {
      signature: generateSignature(qrId, SECRET_KEY),
      version: 2,
      encryption: 'AES-256'
    },
    gps: {
      required: config.gpsRequired,
      center: config.churchCoordinates,
      radius: config.allowedRadius
    }
  };
  
  // Step 5: Generate QR image
  const qrImage = QRCode.create(encrypt(qrData));
  
  // Step 6: Store in database
  database.store({
    qrId,
    generatedBy: adminUser.id,
    generatedAt: timestamp,
    config: config,
    status: 'PENDING_ACTIVATION'
  });
  
  // Step 7: Return QR code
  return {
    image: qrImage,
    id: qrId,
    activationTime: activation,
    expirationTime: expiration
  };
}
```

```javascript
// Mobile app scanning logic
async function scanQRCode() {
  try {
    // Step 1: Activate camera
    const scanner = await activateCamera();
    
    // Step 2: Capture QR code
    const qrData = await scanner.scan();
    
    // Step 3: Decrypt and validate
    const decrypted = decrypt(qrData);
    
    // Step 4: Check expiration
    if (!isValidTime(decrypted.validity)) {
      throw new Error('QR Code has expired or not yet active');
    }
    
    // Step 5: Verify GPS location
    if (decrypted.gps.required) {
      const location = await getCurrentLocation();
      if (!isWithinRadius(location, decrypted.gps)) {
        throw new Error('You must be at church premises to scan');
      }
    }
    
    // Step 6: Check for duplicate scan
    if (await isDuplicateScan(decrypted.id, userId)) {
      throw new Error('You have already scanned this code');
    }
    
    // Step 7: Process based on type
    const result = await processQRType(decrypted.type, decrypted.data);
    
    // Step 8: Store locally if offline
    if (!isOnline()) {
      await storeOffline(result);
      showMessage('Saved offline. Will sync when connected.');
    } else {
      // Step 9: Sync with server
      await syncWithServer(result);
    }
    
    // Step 10: Show success
    showSuccess(result);
    
  } catch (error) {
    showError(error.message);
    logError(error);
  }
}
```

### Dynamic Time Validation

```javascript
class QRTimeValidator {
  constructor(qrData) {
    this.activationTime = new Date(qrData.validity.activates);
    this.expirationTime = new Date(qrData.validity.expires);
    this.graceperiod = qrData.validity.gracePeriod || 0;
  }
  
  isValid() {
    const now = new Date();
    const serverTime = this.getServerTime(); // Sync with server time
    
    // Use server time if available, otherwise device time
    const currentTime = serverTime || now;
    
    // Check if QR is active
    if (currentTime < this.activationTime) {
      const minutesUntilActive = this.getMinutesUntil(this.activationTime);
      throw new Error(`This QR code will be active in ${minutesUntilActive} minutes`);
    }
    
    // Check if QR has expired
    if (currentTime > this.expirationTime) {
      // Check grace period
      const graceExpiration = new Date(this.expirationTime.getTime() + this.graceperiod * 60000);
      if (currentTime > graceExpiration) {
        throw new Error('This QR code has expired. Please contact an administrator.');
      }
      
      // Within grace period
      return {
        valid: true,
        warning: 'Late arrival recorded'
      };
    }
    
    return {
      valid: true,
      remainingMinutes: this.getMinutesUntil(this.expirationTime)
    };
  }
  
  getMinutesUntil(targetTime) {
    const now = new Date();
    return Math.floor((targetTime - now) / 60000);
  }
  
  getServerTime() {
    // Sync with NTP server or church server
    try {
      return syncTimeWithServer();
    } catch {
      return null;
    }
  }
}
```

### GPS Verification Implementation

```javascript
class LocationVerifier {
  constructor(churchConfig) {
    this.churches = churchConfig.locations;
    this.accuracy = 20; // meters
  }
  
  async verifyLocation(requiredLocation) {
    try {
      // Get current position with high accuracy
      const position = await this.getCurrentPosition();
      
      // Check GPS accuracy
      if (position.coords.accuracy > 50) {
        return {
          valid: false,
          error: 'GPS signal too weak. Please move to an open area.'
        };
      }
      
      // Calculate distance to church
      const distance = this.calculateDistance(
        position.coords,
        requiredLocation.center
      );
      
      // Check if within radius
      if (distance <= requiredLocation.radius) {
        return {
          valid: true,
          distance: distance,
          zone: 'INSIDE_PREMISES'
        };
      }
      
      // Check if in grace zone (parking lot, etc.)
      if (distance <= requiredLocation.radius * 1.5) {
        return {
          valid: true,
          distance: distance,
          zone: 'GRACE_ZONE',
          warning: 'You are in the parking area'
        };
      }
      
      // Outside acceptable range
      return {
        valid: false,
        distance: distance,
        error: `You are ${Math.round(distance)}m away from church premises`,
        directions: this.getDirections(position.coords, requiredLocation.center)
      };
      
    } catch (error) {
      // Handle GPS errors
      if (error.code === 1) {
        return {
          valid: false,
          error: 'Location access denied. Please enable GPS.'
        };
      }
      
      throw error;
    }
  }
  
  getCurrentPosition() {
    return new Promise((resolve, reject) => {
      navigator.geolocation.getCurrentPosition(
        resolve,
        reject,
        {
          enableHighAccuracy: true,
          timeout: 10000,
          maximumAge: 0
        }
      );
    });
  }
  
  calculateDistance(coords1, coords2) {
    // Haversine formula for distance calculation
    const R = 6371e3; // Earth radius in meters
    const φ1 = coords1.latitude * Math.PI/180;
    const φ2 = coords2.lat * Math.PI/180;
    const Δφ = (coords2.lat - coords1.latitude) * Math.PI/180;
    const Δλ = (coords2.lng - coords1.longitude) * Math.PI/180;
    
    const a = Math.sin(Δφ/2) * Math.sin(Δφ/2) +
              Math.cos(φ1) * Math.cos(φ2) *
              Math.sin(Δλ/2) * Math.sin(Δλ/2);
    const c = 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1-a));
    
    return R * c;
  }
}
```

### Database Schema

```sql
-- QR Codes Table
CREATE TABLE qr_codes (
    id UUID PRIMARY KEY,
    type VARCHAR(50) NOT NULL,
    church_id VARCHAR(50) NOT NULL,
    service_date DATE,
    service_type VARCHAR(50),
    activation_time TIMESTAMP NOT NULL,
    expiration_time TIMESTAMP NOT NULL,
    location_required BOOLEAN DEFAULT true,
    location_coordinates POINT,
    location_radius INTEGER DEFAULT 100,
    generated_by UUID REFERENCES users(id),
    generated_at TIMESTAMP DEFAULT NOW(),
    status VARCHAR(20) DEFAULT 'PENDING',
    revoked BOOLEAN DEFAULT false,
    revoked_by UUID REFERENCES users(id),
    revoked_at TIMESTAMP,
    metadata JSONB
);

-- QR Scan Logs Table
CREATE TABLE qr_scan_logs (
    id UUID PRIMARY KEY,
    qr_id UUID REFERENCES qr_codes(id),
    user_id UUID REFERENCES users(id),
    scan_time TIMESTAMP DEFAULT NOW(),
    location POINT,
    device_id VARCHAR(100),
    ip_address INET,
    success BOOLEAN,
    error_reason VARCHAR(200),
    processing_time INTEGER, -- milliseconds
    offline_sync BOOLEAN DEFAULT false,
    metadata JSONB
);

-- QR Analytics Table
CREATE TABLE qr_analytics (
    id UUID PRIMARY KEY,
    qr_id UUID REFERENCES qr_codes(id),
    date DATE,
    total_scans INTEGER DEFAULT 0,
    unique_users INTEGER DEFAULT 0,
    success_rate DECIMAL(5,2),
    avg_scan_time INTEGER, -- milliseconds
    peak_time TIMESTAMP,
    peak_scans INTEGER,
    error_count INTEGER DEFAULT 0,
    offline_syncs INTEGER DEFAULT 0,
    hourly_distribution JSONB,
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- Indexes for performance
CREATE INDEX idx_qr_codes_status ON qr_codes(status);
CREATE INDEX idx_qr_codes_dates ON qr_codes(activation_time, expiration_time);
CREATE INDEX idx_qr_scan_logs_qr ON qr_scan_logs(qr_id);
CREATE INDEX idx_qr_scan_logs_user ON qr_scan_logs(user_id);
CREATE INDEX idx_qr_scan_logs_time ON qr_scan_logs(scan_time);
```

## 🆘 Troubleshooting Guide

### Common Issues & Solutions

```yaml
QR Won't Scan:
  Causes:
    - Poor lighting
    - Damaged QR code
    - Camera issues
    - QR expired
  Solutions:
    - Use flash/improve lighting
    - Request QR reprint
    - Clean camera lens
    - Check time settings

GPS Verification Failed:
  Causes:
    - GPS disabled
    - Poor GPS signal
    - Outside church premises
  Solutions:
    - Enable location services
    - Move to open area
    - Move closer to church
    - Use manual check-in

QR Expired Message:
  Causes:
    - Arrived too early/late
    - Wrong service selected
    - Clock sync issues
  Solutions:
    - Wait for activation time
    - Verify service time
    - Sync device time
    - Contact usher

Duplicate Scan Error:
  Causes:
    - Already checked in
    - Family member scanned
    - System error
  Solutions:
    - Verify attendance status
    - Check family scan
    - Clear app cache
    - Contact support
```
