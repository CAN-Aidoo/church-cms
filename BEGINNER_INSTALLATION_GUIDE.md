# 📚 Beginner's Installation Guide

## Welcome! 👋

This guide will walk you through installing and running the Church Management System step-by-step. Don't worry if you're new to this - we'll explain everything!

## What You Need to Install First

Before starting, make sure you have these tools installed on your computer:

### 1. **XAMPP** (Already Installed! ✅)
   - You mentioned you're using XAMPP, which provides:
     - PHP (the programming language)
     - MySQL (the database)
     - Apache (the web server)
   
   **Check if XAMPP is running:**
   - Open XAMPP Control Panel
   - Make sure **Apache** and **MySQL** are running (green indicators)

### 2. **Composer** (PHP Dependency Manager)
   - Download from: https://getcomposer.org/download/
   - Choose the "Composer-Setup.exe" for Windows
   - During installation, it will ask for PHP path - use: `C:\xampp\php\php.exe`
   - After installation, open a new Command Prompt and type: `composer --version` to verify

### 3. **Node.js and NPM** (For Frontend Assets)
   - Download from: https://nodejs.org/
   - Choose the LTS (Long Term Support) version
   - Install it (this also installs NPM automatically)
   - After installation, open Command Prompt and type:
     - `node --version` (should show v18.x or higher)
     - `npm --version` (should show 9.x or higher)

### 4. **Git** (If you need to clone the repository)
   - Download from: https://git-scm.com/download/win
   - Use default settings during installation

### 5. **Redis** (Optional but Recommended)
   - Redis is used for caching and background jobs
   - For Windows, you can use Memurai (Redis alternative): https://www.memurai.com/
   - Or use Redis for Windows from: https://github.com/microsoftarchive/redis/releases
   
   **Note:** If you skip Redis, you can still run the system, but you'll need to change some settings later.

## Step-by-Step Installation

### Step 1: Navigate to Your Project Folder

1. Open **Command Prompt** (Press `Win + R`, type `cmd`, press Enter)
2. Navigate to your project folder:
   ```bash
   cd C:\xampp\htdocs\church-cms-docs
   ```
   
   **What this does:** Changes your current directory to where the project files are located.

---

### Step 2: Install PHP Dependencies

```bash
composer install
```

**What this does:** 
- Downloads all PHP libraries needed by the project (like Laravel framework)
- Creates a `vendor` folder with all dependencies
- This might take 2-5 minutes depending on your internet speed

**Common Issues:**
- If you get "composer is not recognized": Make sure Composer is installed and restart your Command Prompt
- If it's slow: This is normal, just wait

---

### Step 3: Install Node.js Dependencies

Open a **new Command Prompt** (keep the first one open) and run:

```bash
cd C:\xampp\htdocs\church-cms-docs
npm install
```

**What this does:**
- Downloads all JavaScript/CSS libraries (like Tailwind CSS, Alpine.js)
- Creates a `node_modules` folder
- This might take 3-5 minutes

---

### Step 4: Create Environment Configuration File

The `.env` file stores your database passwords and settings. Let's create it:

1. In your project folder, look for a file named `.env.example`
   - If it doesn't exist, we'll create one

2. Copy it to create `.env`:
   ```bash
   copy .env.example .env
   ```
   
   **Or if .env.example doesn't exist:**
   ```bash
   copy nul .env
   ```
   Then we'll add content to it in the next step.

3. Generate Application Key:
   ```bash
   php artisan key:generate
   ```
   
   **What this does:** Creates a secret key that Laravel uses to encrypt data

---

### Step 5: Configure the .env File

Open the `.env` file in a text editor (Notepad, VS Code, etc.) and configure these important settings:

```env
# Application
APP_NAME="Church Management System"
APP_ENV=local
APP_KEY=base64:... (already generated by previous step)
APP_DEBUG=true
APP_URL=http://localhost:8000

# Database Configuration (for XAMPP)
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=church_management
DB_USERNAME=root
DB_PASSWORD=

# Church Information
CHURCH_NAME="Your Church Name"
CHURCH_ADDRESS="Your Church Address"
CHURCH_PHONE="+1234567890"

# Mail Configuration (for testing, you can use Mailtrap)
MAIL_MAILER=smtp
MAIL_HOST=mailpit
MAIL_PORT=1025
MAIL_USERNAME=null
MAIL_PASSWORD=null
MAIL_ENCRYPTION=null
MAIL_FROM_ADDRESS="noreply@churchcms.com"
MAIL_FROM_NAME="${APP_NAME}"

# Twilio SMS (Optional - leave empty if you don't have Twilio)
TWILIO_SID=
TWILIO_TOKEN=
TWILIO_PHONE=
TWILIO_ENABLED=false

# Redis Configuration (if you installed Redis)
CACHE_DRIVER=file
QUEUE_CONNECTION=sync
SESSION_DRIVER=file

# If you have Redis installed, uncomment these:
# CACHE_DRIVER=redis
# QUEUE_CONNECTION=redis
# SESSION_DRIVER=redis
# REDIS_HOST=127.0.0.1
# REDIS_PASSWORD=null
# REDIS_PORT=6379
```

**Important Settings to Change:**
- `DB_DATABASE`: The name of your database (we'll create it next)
- `DB_PASSWORD`: Leave empty if XAMPP MySQL has no password (default)
- `CHURCH_NAME`: Your actual church name
- `CHURCH_ADDRESS`: Your church address
- `CHURCH_PHONE`: Your church phone number

**Save the file when done!**

---

### Step 6: Create the Database

1. **Open phpMyAdmin:**
   - Go to: http://localhost/phpmyadmin
   - Or click "Admin" next to MySQL in XAMPP Control Panel

2. **Create a new database:**
   - Click "New" in the left sidebar
   - Database name: `church_management`
   - Collation: `utf8mb4_unicode_ci`
   - Click "Create"

**Alternative: Using Command Line**
```bash
# Open MySQL command line from XAMPP
C:\xampp\mysql\bin\mysql.exe -u root -e "CREATE DATABASE church_management CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"
```

---

### Step 7: Run Database Migrations

Go back to your Command Prompt (in the project folder) and run:

```bash
php artisan migrate
```

**What this does:**
- Creates all the database tables needed by the system
- Sets up the structure for members, attendance, finances, etc.
- This might take 1-2 minutes

**Common Issues:**
- "Access denied": Check your database username/password in `.env`
- "Unknown database": Make sure you created the database in Step 6

---

### Step 8: Seed Sample Data (Optional but Recommended)

This adds test data so you can see how the system works:

```bash
php artisan db:seed
```

**What this does:**
- Creates sample members, users, and other data
- Creates default login accounts you can use
- Makes it easier to explore the system

**Default Login Accounts Created:**
- **Admin:** admin@churchcms.com / password: `password`
- **Pastor:** pastor@churchcms.com / password: `password`
- **Staff:** staff@churchcms.com / password: `password`

> ⚠️ **Important:** Change these passwords before using in production!

---

### Step 9: Create Storage Link

```bash
php artisan storage:link
```

**What this does:**
- Creates a symbolic link so uploaded files (photos, documents) can be accessed via the web

---

### Step 10: Build Frontend Assets

You have two options:

**Option A: Development Mode (for learning/development)**
```bash
npm run dev
```
- Keep this command running
- It watches for changes and rebuilds automatically
- Open a **new Command Prompt** for the next steps

**Option B: Production Build (one-time build)**
```bash
npm run build
```
- Builds everything once
- Use this when you're ready to go live

---

### Step 11: Set Folder Permissions (Important!)

Laravel needs write access to certain folders:

**In Command Prompt (as Administrator):**
```bash
# Navigate to project folder
cd C:\xampp\htdocs\church-cms-docs

# Give write permissions (Windows)
icacls storage /grant Users:F /T
icacls bootstrap\cache /grant Users:F /T
```

**Or manually:**
1. Right-click the `storage` folder → Properties → Security
2. Click "Edit" → Select "Users" → Check "Full control" → OK
3. Repeat for `bootstrap/cache` folder

---

### Step 12: Start the Development Server

In a new Command Prompt:

```bash
cd C:\xampp\htdocs\church-cms-docs
php artisan serve
```

**What this does:**
- Starts a web server on your computer
- You'll see: "Laravel development server started: http://127.0.0.1:8000"

**Keep this window open!** The server runs as long as this window is open.

---

### Step 13: Access the Application

Open your web browser and go to:

```
http://localhost:8000
```

You should see the Church Management System login page!

**Try logging in with:**
- Email: `admin@churchcms.com`
- Password: `password`

## Troubleshooting Common Issues

### ❌ "Composer not found"
**Solution:** 
- Make sure Composer is installed
- Restart Command Prompt
- Add Composer to your PATH environment variable

### ❌ "PHP not found" or "php artisan" doesn't work
**Solution:**
- Add PHP to your PATH:
  - Open System Properties → Environment Variables
  - Add `C:\xampp\php` to Path
  - Restart Command Prompt

### ❌ Database connection error
**Solution:**
1. Check if MySQL is running in XAMPP
2. Verify database name in `.env` matches what you created
3. Check username/password in `.env`

### ❌ "Permission denied" errors
**Solution:**
- Run Command Prompt as Administrator
- Check folder permissions for `storage` and `bootstrap/cache`

### ❌ Port 8000 already in use
**Solution:**
```bash
php artisan serve --port=8001
```
Then access at: http://localhost:8001

### ❌ Page shows errors or blank page
**Solution:**
1. Clear cache:
   ```bash
   php artisan optimize:clear
   ```
2. Check `.env` file exists and has correct settings
3. Make sure you ran `php artisan key:generate`

### ❌ CSS/JS not loading
**Solution:**
- Make sure you ran `npm run dev` or `npm run build`
- Check browser console for errors
- Clear browser cache (Ctrl + F5)

## What Each Tool Does (Beginner's Guide)

### **Composer**
- PHP's package manager
- Downloads and manages PHP libraries
- Think of it like an app store for PHP code

### **NPM (Node Package Manager)**
- JavaScript's package manager
- Downloads and manages JavaScript/CSS libraries
- Needed for Tailwind CSS and other frontend tools

### **MySQL**
- Database system (stored in XAMPP)
- Stores all your data (members, attendance, etc.)
- Managed through phpMyAdmin

### **phpMyAdmin**
- Web interface for MySQL
- Access at: http://localhost/phpmyadmin
- Easy way to view/edit database without coding

### **Laravel Artisan**
- Command-line tool for Laravel
- Commands start with `php artisan`
- Used for migrations, creating code, etc.

### **.env File**
- Configuration file
- Stores passwords, database settings, etc.
- **Never share this file!** It contains sensitive information

## Getting Help

If you encounter issues:

1. **Check Error Messages:**
   - Read the full error message
   - Look for specific file names or line numbers

2. **Check Logs:**
   - Laravel logs: `storage/logs/laravel.log`
   - Check for error messages there

3. **Common Solutions:**
   - Clear cache: `php artisan optimize:clear`
   - Rebuild assets: `npm run build`
   - Check `.env` file configuration

4. **Verify Requirements:**
   - PHP 8.2+: `php --version`
   - MySQL running: Check XAMPP Control Panel
   - Composer installed: `composer --version`
   - Node.js installed: `node --version`
