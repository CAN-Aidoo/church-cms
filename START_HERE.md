**→ Use: [setup-windows.bat](setup-windows.bat)**

Double-click this file to automatically:
- Install dependencies
- Create configuration files
- Generate application key
- Set up storage links

**Then** follow the manual steps it shows you (database setup, etc.)

**Perfect if you:**
- Are on Windows
- Want to automate the repetitive steps
- Still need to do database setup manually

## 💡 Quick Tips

### Before You Start
- ✅ Make sure XAMPP is installed (if you're using it)
- ✅ Have Composer and Node.js installed
- ✅ Have a text editor ready (VS Code, Notepad++, etc.)

### During Installation
- 💾 Save important information (passwords, database names)
- 📝 Read error messages carefully
- 🔍 Check the troubleshooting sections if stuck

### After Installation
- 🔐 Change default passwords immediately
- 📖 Explore the system with sample data
- 🎨 Customize church information in settings

---

## 🆘 Need Help?

1. **Check the troubleshooting section** in your chosen guide
2. **Read error messages** carefully - they usually tell you what's wrong
3. **Check logs**: `storage/logs/laravel.log`
4. **Verify requirements**: Make sure all tools are installed
